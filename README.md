# Client Base

> ⚠️ **Тестовый кейс.** Небольшое учебное приложение, а не полноценная CRM. Предназначено для демонстрации базовых навыков работы с Angular.

Простое приложение для управления списком пользователей: просмотр, добавление, удаление.

## Стек

- Angular 18
- Angular Material / CDK
- TypeScript 5.5
- RxJS 7.8

## Запуск

```bash
npm install
npm start        # http://localhost:4200
```

## Скрипты

| Команда         | Назначение                    |
| --------------- | ----------------------------- |
| `npm start`     | dev-сервер                    |
| `npm run build` | production-сборка             |

## Функциональность

- Список пользователей
- Добавление пользователя
- Удаление пользователя

## Цель кейса

- Работа с компонентами Angular Material.
- Базовый CRUD на клиенте.
