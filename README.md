# Task Board

> ⚠️ **Тестовый кейс.** Учебный проект, а не полноценный таск-трекер. Служит для практики работы с состоянием в Angular.

Канбан-доска: создание задач, перемещение между статусами, удаление.

## Стек

- Angular 18
- Angular Material / CDK
- TypeScript 5.5
- RxJS 7.8

## Запуск

```bash
npm install
npm start        # http://localhost:4200
```

## Скрипты

| Команда         | Назначение                          |
| --------------- | ----------------------------------- |
| `npm start`     | dev-сервер                          |
| `npm run build` | сборка                              |
| `npm run watch` | сборка в watch-режиме (development) |

## Функциональность

- Создание задач
- Перемещение задач между колонками-статусами
- Удаление задач

## Цель кейса

- Управление состоянием списков задач.
- Работа с `@angular/cdk`.
